💳 Credit Card Fraud Detection

📌 About the Project
This project is used to detect whether a credit card transaction is fraud or not using machine learning. It helps banks and users to prevent financial loss.

🎯 Goal
Identify fraudulent transactions
Improve security in online payments

🛠️ Tools Used
Python
Pandas, NumPy
Scikit-learn
Matplotlib

📊 Dataset
Contains transaction details
Output:
0 → Normal transaction
1 → Fraud transaction

⚙️ How it Works
Load the dataset
Clean and process the data
Train the model
Test the model
Predict fraud or not

🤖 Models Used
Logistic Regression
Random Forest

📈 Result
The model can successfully detect fraud transactions with good accuracy.

▶️ How to Run
Download the project
Install required libraries
Open Jupyter Notebook
Run the code
